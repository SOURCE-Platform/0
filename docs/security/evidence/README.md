# Manual evidence notes

One file per ID that only a person or a physical device can show (device
runs IO-01…07, PV-01, EV-03; the Chrome probe NM-05/NM-06; panel checks
UI-02/UI-04; capture checks CS-01…05). `scripts/vault-id-gate.py` fails a
gate while the note is missing. Each note says: date, device or setup,
what was done, what was seen, and who ran it. Synthetic data only.
